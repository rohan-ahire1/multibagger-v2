# M116: net buying in bulk and block deals as a filter on the momentum picks (pre-registered 2026-10-04)

Asked by the user ("keep improving"; idea 1 of the M113 follow-ups). A bulk deal is one client trading more than 0.5% of
a company's shares in a day; block deals are large trades in the separate block window. Big buyers taking stock
(funds, promoters) may confirm a momentum name; big sellers may mean supply is coming.

## Data

NSE bulk and block deals from the CSV export of the history API (`data/raw/nse_bulk_deals_full`,
`data/raw/nse_block_deals_full`, copied from india-market-data, fetcher `fetchers/fetch_nse_deals_csv.py`, 2010-01 to
2026-10). The JSON form used for the older folders is cut at 70 rows a day (40% of rows sit on cut days); the CSV
form is not (30-Sep-2026: 179 rows vs 70). Identical rows within a folder count once.
Value = quantity x price, + for a buy, - for a sell, all clients. A deal counts from the day after it (NSE publishes
the list that evening). Symbol as traded.

Signal at a decision d: net value of deals usable at d in the 90 calendar days before d (M111's code). The rule is off
for decisions before the data covers a full window (January-March 2010).

## Candidates (M106 + one change each; the M111 rules on this signal)

- `m116_nosell`: a name not already held is not bought if its net deal value is below 0.
- `m116_buyfirst`: new buys first take names with net deal value above 0 ranked under 50 (in rank order), then the
  rest in rank order.

## Pass (each candidate, against M106; dev 2010-01-04..2023-12-31; same bar as M114)

- offset 0 (vs run 20261002-050950-93574646): Calmar higher before and after tax (M110 model) on the whole period,
  and before tax on at least 2 of f1/f2/f3;
- offsets 5/10/15 (vs `m111_ref_offN`): before-tax whole-period Calmar higher at all three;
- then one locked look, 2024-01-01..2026-09-28 at offset 0 (vs final run 20261002-054052-94c22192): Calmar before and
  after tax not lower. If both pass, the one with the higher offset-0 after-tax whole-period Calmar takes it.
Expectation: unknown. Matched deals (a reported buyer and a reported seller) cancel, so the signal is the unmatched
side; operator round trips in small caps also cancel.
