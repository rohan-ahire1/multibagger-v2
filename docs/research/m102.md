# M102: stop-loss neighbours of the M95 book

## Question

M96 tested M95's filter settings (150/250 days; ¼ and ¾ to gold) but not its 10% stop. How sensitive is the passing
book to the stop level? Neighbours a step either side: 7.5% and 15% (M73 tested 10/15/20% on the plain stop book;
10% was best there).

| Candidate | Change |
|---|---|
| `m102_s075_r50g_jr*` | `m95_r50g_jr*` with `stop_loss_frac: 0.075` |
| `m102_s15_r50g_jr*` | `m95_r50g_jr*` with `stop_loss_frac: 0.15` |

Mainly information (robustness); a neighbour that beats M95 on every line would still be a picked neighbour, so it is
reported, not proposed. Same checks and bar. Disclosure: M95/M96 seen first.

## Results (runs in `reports/m102_runs.txt`)

| Tranches | 2010–23 | Folds | 25 bps | 2007–09 |
|---|---|---|---|---|
| 7.5% stop | 31.33%, 17.06%, **1.837** — run 20261002-045215-4e3e6d98 | 1.853 / 2.654 / 1.949 | 1.625 (run 20261002-045254-3c12ff8e) | 0.691 |
| 10% (M95) | 33.44%, 20.19%, 1.656 — run 20261002-041639-baa42e53 | 1.784 / 2.731 / 1.763 | 1.497 | 0.591 |
| 15% stop | 35.47%, 25.12%, 1.412 — run 20261002-045336-687e7c56 | 1.824 / 2.626 / 1.518 | 1.302 (run 20261002-045416-86da3288) | 0.563 |

Offset 0 alone: 7.5% 1.862 (1.779 / 1.873 / 2.217; fails f2), 15% 1.345 (1.776 / 2.098 / 1.515; passes).

**Verdict:** M95 is not fragile in its stop: both neighbours' tranches pass the bar at 5 and 25 bps. The stop is a
dial between return and drawdown: 7.5% gives up 2 points of CAGR for 3 points less drawdown (Calmar 1.84), 15% adds
2 points of CAGR for 5 points more drawdown (1.41). As pre-registered, 7.5% is a picked neighbour and is reported,
not proposed; it is a fair choice if drawdown matters more than return.
