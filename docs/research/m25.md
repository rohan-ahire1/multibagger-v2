# M25: the untouched early window, 2007–2009

Pre-registration, written and committed before any run on this window (2026-09-30, Claude). No `--final`.

## Why

Every choice so far (inverse-vol weights in M11, the clean universe in M13, the data fixes of M14–M18, the gold sleeve
in M19) was made on 2010–2023. The dataset has bars and corporate actions from 2005, and nothing has ever been scored
on 2005–2009. That makes it the only window left that no decision was fitted on, and it holds the worst Indian bear
market of the period (Nifty fell about 60% from January 2008 to March 2009) and the sharp 2009 rebound, when momentum
books usually do badly. A strategy chosen on 2010–2023 that holds up here is more believable.

## Window

2007-04-02 → 2009-12-31 (2.75 years). GOLDBEES listed 2007-03-19, so the first decision (2007-04-30) can hold it.
Lookbacks read 2006 bars. Same dataset (`nse_research@2026-09-30c`), market and params as the source configs; only
`version` and `period` differ. The Nifty 500 TRI file starts 2010-01-04, so that baseline is empty for this window
(`baselines.compute` now leaves a window the file does not cover empty; existing configs all start 2010-01-04 and are
unchanged). The 12-1 momentum baseline runs as usual, and the notebook adds NIFTYBEES buy-and-hold as a market reference.

## Hypotheses, fixed now

- H1 (gold): the 20% sleeve has a higher Calmar than its no-gold twin on each of the four books.
- H2 (inverse-vol): inverse-vol has a higher Calmar than equal weight on both books.

Calmar may be negative on this window; higher is still better. Also reported: CAGR, max DD and its dates, the 12-1
baseline, NIFTYBEES buy-and-hold.

## What follows from the result

Nothing is adopted or dropped here; this is evidence. If H1 fails on two or more of the four books, the gold
recommendation is marked weakened in `m19.md`, `m24.md` and the paper draft. The same goes for H2 and inverse-vol. If
the data gate refuses a run (an unexplained jump in a traded name), the names are listed and the run is not forced;
fixing pre-2010 data would be its own milestone.

## Disclosure

- Known before this: gold rose strongly in rupees in 2008 (widely known), so H1 is not a blind test. What is not
  known is the size of the effect, and whether gold's weight drags on the 2009 rebound.
- Pre-2010 data has not had the M14/M16/M18 corporate-action reviews; unexplained jumps are more likely.
- Nothing from 2005–2009 has been looked at in this project beyond the M11 note that some pre-2010 symbols had
  fund-unit ISINs.
