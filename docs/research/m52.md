# M52: the walk-forward process as one out-of-sample curve (information)

Not pre-registered: a measurement on existing runs, no selection. Notebook `notebooks/m52_stitched.py`.

## What

Each period uses the setting M42 chose from earlier data only: step A's setting (trained 2010–13) for 2014–17,
step B's (2010–17) for 2018–20, step C's (2010–20) for 2021–23. Daily returns from the offset-0 M49 runs
(A 20261002-000447-e95b8299, B 20261002-000352-0103cc7f, C 20261002-000306-0ff2d949), chained. This is what "re-tune
every few years" would have earned, with no look-ahead in the settings (only in the search's design, which M41 set
after M40).

## Results

| 2014–2023 | CAGR | Max DD | Calmar |

| **stitched walk-forward (out of sample)** | 24.84% | 26.07% | **0.953** |
| old pin (settings chosen seeing all of 2010–23) | 32.93% | 31.39% | 1.049 |
| new pin B (tuned on 2010–17) | 32.90% | 26.07% | 1.262 |

| Piece | Selected setting | Old pin |
|---|---|---|
| 2014–17 (A) | 20.09% / 12.90% / 1.557 | 35.12% / 17.72% / 1.982 |
| 2018–20 (B) | 21.26% / 26.07% / 0.816 | 17.88% / 31.39% / 0.570 |
| 2021–23 (C) | 35.48% / 15.62% / 2.271 | 46.88% / 23.83% / 1.967 |

- The honest out-of-sample figure for this research process is **Calmar about 0.95 at about 25% CAGR**, not 1.1–1.3.
  Both pins' 2014–23 numbers include in-sample fit.
- The tuned settings cut drawdown every time (12.9 vs 17.7, 26.1 vs 31.4, 15.6 vs 23.8) and gave up return in the two
  strong periods. Tuning for Calmar mostly buys a smaller drawdown.
- Expectation for the new pin going forward: between 0.95 and 1.1; anything above 1.1 on the locked period would be
  better than this history suggests.
