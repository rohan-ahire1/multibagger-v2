# M111: insider buying and selling as a filter on the momentum picks (pre-registered 2026-10-04)

Asked by the user (idea 1 of the M110 follow-ups). Research elsewhere finds open-market buying by insiders predicts
returns and heavy selling is a warning. Nothing in the book uses it yet.

## Data

SEBI PIT disclosures from NSE (`data/raw/nse_insider_pit/`, copied from india-market-data `data/nse_insider_pit`,
broadcasts 2015-11 to 2026-04; NSE has returned nothing since May 2026 and BSE blocks scripted access, so a live
source is an open problem to solve only if this passes).
Kept: acquisition mode "Market Purchase" (+ value) or "Market Sale" (- value); person category Promoters, Promoter
Group, Director, Key Managerial Personnel; duplicates across exchanges dropped (same symbol, person, dates, quantity,
mode). A filing counts from the day after its NSE broadcast date (no look-ahead). Symbol as filed (a later rename
loses the history: known limitation).

Signal at a decision date d: net value (buys - sells, Rs) of kept filings broadcast in the `lookback_days` (90) calendar
days before d. The rule is off for decisions before first broadcast + lookback (so 2010 to early 2016 equals M106) and
refuses decisions more than 7 days after the last broadcast.

## Candidates (written before any M111 run; M106 + one change each)

- `m111_nosell`: a name not already held is not bought if its net insider value is below 0.
- `m111_buyfirst`: new buys first take names with net insider value above 0 ranked under 50 (in rank order), then
  the rest in rank order.

## Pass (each candidate, against M106 run 20261002-050950-93574646)

Window where the rule is live: 2016-04-01 to 2023-12-31 ("live"), plus f3 (2018-23).
- before-tax Calmar higher than M106 on "live" and on f3, and not lower on f2;
- after-tax Calmar (M110 model) higher on "live";
- then one locked look, 2024-01-01 to 2026-04-30 (data end): must not be worse than M106 before tax on Calmar.
Expectation: unknown; most months only a few of the ~50 candidates will have filings.
