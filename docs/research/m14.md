# M14: keep a renamed stock's price history

Pre-registration, written and committed before the new dataset is built or any M14 run (2026-09-30, Claude working
alone overnight at the user's request). Development period 2010-01-04..2023-12-31 only; no `--final`.

## The problem

Every indicator is computed per symbol. When a company changes its trading symbol (same ISIN, new symbol), the old
symbol's bars stop and the new symbol starts with no history:

- the name cannot be ranked until the new symbol has `lookback_sessions` (252) rows, about a year;
- a held name's old symbol has no bars after the rename, so the backtest sells it at its last close at the next
  rebalance (up to a month stale), and paper trading does the same.

In `nse_research@2026-09-29f`, 274 stock ISINs changed symbol between 2009 and 2023; 70 of them had ₹5 crore or more
of daily turnover at the time (above `min_adv_inr`). Examples: NIITTECH → COFORGE (2020-08), ADANIGAS → ATGL
(2021-01, before its 2021 rise), TATAGLOBAL → TATACONSUM (2020-02), RNAM → NAM-INDIA (2020-01), WELSPUNIND →
WELSPUNLIV (2023-12). Found while checking fill sizes for M13: 20 of `m13_clean_invvol_b2`'s sells had no bar on the
day; 19 were renames or mergers, and one (FORCEMOT, 2023-11..2024-02) is absent from NSE's own bhavcopies.

## The fix (data config option; a new dataset version)

`link_renames_by_isin` (a `DataConfigM14`; existing data configs keep their model and hash). At build time, before
corporate actions are matched:

1. For each ISIN, list the symbols that carried it and each one's first and last session with it. Consecutive symbols
   whose spans do not overlap form a link `old → new`, dated by `new`'s first session. A link is refused if `old`'s
   last bar is more than `rename_max_gap_days` (31) calendar days before `new`'s first: the series would join prices
   from before a long suspension, and a 252-session lookback would reach across it.
2. Every bar of `old` dated on or before that session is relabelled `new` (chains follow: A → B → C gives C). The
   bar keeps its `security_id`. A link is dropped if it would give one symbol two bars on one session (reported).
3. Overrides and verified moves written against `old` on or before that date are relabelled the same way; feed
   actions are already mapped to bar symbols by ISIN.
4. Adjustment, dividend steps, jump detection and checks then run as before, on the linked series. A link that joins
   two different price levels shows up as an unexplained jump and is refused by the data gate, as any jump is.

The strategy code does not change. Renames before ISINs appear in the bhavcopy (mid-2011) cannot be linked this way.
Trade records use the later symbol, which is known only later: that is a label, not information about prices.
Paper trading's data config (`nse_daily.yaml`) is not changed.

## Runs (question `momentum-m14-linked`)

A new data config `configs/data/nse_research_linked.yaml` (identical to `nse_research.yaml` plus the option) builds
`nse_research@2026-09-30`. The M13 clean configs are copied with only the dataset changed:

| Config | Is |
|---|---|
| `m14_linked_b1` | `m13_clean_b1` on the linked dataset |
| `m14_linked_b2` | `m13_clean_b2` on the linked dataset |
| `m14_linked_invvol_b1` | `m13_clean_invvol_b1` on the linked dataset |
| `m14_linked_invvol_b2` | `m13_clean_invvol_b2` on the linked dataset |

This is a data correction, not a strategy idea, so there is no pass bar. What gets reported: the number of links made
and refused; new unexplained jumps; each run's change against its M13 pin (whole period and folds); and whether
inverse-vol still beats equal weight on both books. If the linked runs differ from M13 by more than 0.05 Calmar, the
cause is traced to named trades before anything else is concluded. If the build fails its checks, the failure is
reported and the M13 pins remain the references.

## Disclosure

- The M13 results are known. The size and sign of the effect of linking are not.
- The gap rule was added after a dry run of the linking on `nse_research@2026-09-29f` (no backtest): 505 links, median
  gap 1 day; 13 gaps of 43 days to 6.8 years (most after a 2015-01-29 last bar), including the only three links whose
  prices jump by more than 1.5× (PERIATEA → PKTEA 2.3×, HYDROS&S → KINGFA 3.3×, KRITIIND → KRITI 14.6×). 31 days is
  one rebalance interval; the next-longest gap below it is 23 days.
- New dataset ~350 MB; the Mac has ~7.8 GB free. Nothing is deleted.
