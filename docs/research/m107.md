# M107: the one final evaluation of the adopted book and the best book (pre-registered 2026-10-02)

The user asked for the locked-period test of both M106 books. Written before any run.

## What runs (each config once, `--final`, 2010-01-04 to 2026-09-28, dataset `nse_research@2026-10-02b`)

1. `m107_final_g25_jr_gap`: the adopted book, `m106_gap30_g25_jr_b2` with only the period changed
   (pin `momentum/m106_g25_jr_gap`).
2. `m107_final_m95_tranche`: the best book, `m95_r50g_jr_tranche_b2` (four tranches), period changed in the blend and
   its four sleeves.

Nothing else changes. The old pin `momentum/m49_b_b2` is not run: its final is a separate decision.

## What is reported

The locked window 2024-01-01 to 2026-09-28 cut from each final curve (`notebooks/m107_final.py`): CAGR, max DD,
Calmar, beside the 12-1 baseline over the same window and the Nifty 500 TRI (its file ends 2026-03-17, so it is
compared over 2024-01-01 to 2026-03-17, with each book cut to the same window). Also the whole 2010-2026 period.

## Decision rule (fixed now)

- If the adopted book beats both baselines on Calmar in the locked window, it stays adopted and goes to paper.
- If it does not, it still goes to paper (2.7 years is short and noisy), but no setting is changed because of this
  result; any later change needs new evidence, not this window.
- M95 is information: if it beats the adopted book here, that supports building its paper support later; nothing is
  tuned on it either.
