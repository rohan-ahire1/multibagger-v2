# M43: paper support for the M40 delivery filter, and the trading-gap check

Engineering and data checks, no new strategy result. 2026-10-02, Claude.

## Paper book with the delivery filter

The paper book refused `universe.delivery_drop_frac` because the daily data had no delivery column. Now:

- `configs/data/nse_daily_delivery.yaml`: `nse_daily_linked.yaml` plus a `delivery` section.
- `mb paper daily` downloads the delivery file for every build session that has none (`daily.fetch_delivery`), and the
  build's `inputs` hash the delivery files, so a late file rebuilds the dataset.
- The book loads `volume` and `deliv_qty` only when the filter is on; a dataset without them is refused.
- Draft book `configs/paper/momentum_top40_gold_deliv.yaml` (pin `m40_deliv40_gold20_b2`, hash 9fc4ae73…). **Not
  deployed**; it needs the user's approval, the delivery files on the VPS and a timer.
- Tests: `tests/test_m43_paper_delivery.py` (213 pass in all).

Real-data check (Mac, scratch store, start 2026-01-30 because the holiday list covers 2026 only): built
`nse_daily_delivery@2026-09-28` (no 2023+ session lacks a delivery file); the book made six month-end decisions, every
one equal to the pin's targets on `nse_research@2026-10-01c`; replay gap −0.55%, no mismatches. It then stopped, as
designed, at 2026-07-31: KOVAI was a pick and has an unexplained ×2.13 jump on 2026-04-20.

## KOVAI and trading gaps

KOVAI has no EQ/BE bars from 2023-10-26 to 2026-04-19 (2.5 years), so the "jump" is the price change across the gap.
Momentum windows count rows, not days: a 252-row lookback across that gap measures a 3-year return, and the name looks
like a leader. The jump gate stopped it here only because the price moved more than 1.5×.

In the pin's 2010–2023 backtest (run 20261001-161755-9fc4ae73), 7 of 2,192 entries had a 252-row window spanning more
than 400 calendar days (normal is 360–380): net P&L in the table below. One had a single gap over 60 days:
KOHINOOR, bought 2023-02-01 with a 770-day gap in its window, −52.8% (−₹1.6 lakh).

| 252-row window spans | entries | P&L (₹) |
|---|---|---|
| > 400 days | 7 | +74,991 |
| > 450 days | 2 | −163,444 |
| > 550 days | 1 | −160,033 |

Total P&L of all entries: ₹3.29 crore on ₹10 lakh. The effect on the backtest is small; the risk is in live trading,
where a returning name can be bought on a stale window. A fix is pre-registered as M44.
