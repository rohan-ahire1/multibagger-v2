# M35: the ₹2 crore floor on the untouched early window, 2007–09

Pre-registration (2026-10-01, Claude), written and committed before any run. Not a development run: the window
2007-04-02..2009-12-31 has been used only by M25/M26 (and M27's diagnostic) and was not used to pick the floor.

## Why

M33 adopted a ₹2 crore liquidity floor on 2010–2023. Thinner stocks fell hardest in 2008, so a lower floor could
make the 2008 loss much worse. The early window is the one honest out-of-sample test available before paper trading.

## Runs (question `momentum-m35-early`, dataset `nse_research@2026-10-01b`, period 2007-04-02..2009-12-31)

| Config | Is |
|---|---|
| `m35_early_gold20_invvol_b2` | the M26 reference (`m26_gold20_invvol_b2`, ₹5 crore) on this dataset |
| `m35_early_adv2cr_gold20_b2` | the pin `m33_adv2cr_gold20_b2` on the early window |

Read as: the floor holds up out of sample if `m35_early_adv2cr_gold20_b2` has the higher Calmar **and** a max
drawdown no more than 5 points worse than the reference. If it fails, the pin stays (the bar is 2010–2023), but
the failure goes into the paper-trading recommendation. Data errors found by the gate are fixed as data, not by
changing the configs.

## Disclosure

Known: M26 gold20_invvol_b2 0.209 (10.07% CAGR, 48.22% DD) on `nse_research@2026-09-30d`; every momentum book lost
48–78% in 2008; M27 rotation 0.586 there. No run with a ₹2 crore floor on this window has been made.

## Amendment 1 (2026-10-01, before any result was looked at): fund units before 2011

The ₹2 crore run stopped: GOLDBEES was both picked and held as the fixed sleeve. `fund_units_by_symbol` learned
which symbols are funds from the run's own panel, which is cut at `period.end`; bhavcopies before mid-2011 carry no
ISIN, so in a run ending in 2009 no fund was known and every ETF (NIFTYBEES, GOLDBEES, JUNIORBEES, …) was eligible as a
stock. Fix (commit after `m35` branch start): the runner reads the fund symbols from the whole dataset; whether a
symbol is a fund is a fact about the listing, not a price. No symbol in `nse_research@2026-10-01b` first gets a fund
ISIN after 2023 while trading as a non-fund before, so no 2010–2023 run can change; the pins
`momentum/m33_adv2cr_gold20_b2` and `momentum/m19_gold20_invvol_b2` re-run exactly (`mb runs verify`).

The reference run made before the fix (20261001-140159-5d14b413) is void and was not looked at. **M25, M26 and the M27
early-window diagnostic may have held ETFs as stocks**; both M35 configs are re-run with the fix, and the
reference's corrected numbers replace M26's 0.209 as the early-window reference from here on.

## Results (2026-10-01)

Early window 2007-04-02..2009-12-31, dataset `nse_research@2026-10-01b`, code with the fund-unit fix:

| Config | Run | CAGR | Max DD (peak → trough) | Calmar |
|---|---|---|---|---|
| `m35_early_gold20_invvol_b2` (₹5 crore reference) | 20261001-140435-5d14b413 | 9.67% | 64.57% (2008-01-07 → 2008-10-27) | 0.150 |
| `m35_early_adv2cr_gold20_b2` (the pin) | 20261001-140436-3149b70f | 7.08% | 65.01% (same) | 0.109 |
| information: `m27_early_rot_gold_b2` re-run with the fix (question `momentum-m35-info`) | 20261001-140455-13599d9a | 33.86% | 41.11% | 0.824 |

- **The early-window references were wrong.** M26's gold20_invvol_b2 (0.209, 48.22% DD) and M27's early rotation
  (0.586) held LIQUIDBEES as if it were a stock (lowest volatility, so the best return/vol score); it acted as cash
  in 2008. With ETFs excluded, the gold20 book lost **65%** in 2008, not 48%. M25/M26 conclusions about gold helping
  in 2008 should be read with this in mind (gold still helps; the levels were too kind).
- The ₹2 crore floor fails this check: lower Calmar (0.109 vs 0.150) and lower CAGR in 2007–09; the drawdown is the
  same (+0.4 points). Thin names did not add return through the 2008 crash and its 2009 rebound. The pin stays (its
  bar is 2010–2023), but the 2010–2023 gain is not confirmed out of sample.
- Book ↔ gold rotation (M27) is the only rule tried that defends a 2008-type crash: 41% drawdown and 34% CAGR over
  2007–09. It failed the 2010–2023 bar on timing luck (M27/M28).
- For paper/live: every stock-only momentum book here, with or without gold, should be expected to lose about two
  thirds in a 2008-type year. Calmar near 0.87 over 2010–2023 has no such year in it.
