# M85: the 10% stop on the out-of-sample walk-forward (information)

## Question

M52 stitched M42's walk-forward for 2014–23: each period uses only the setting chosen from earlier data (A for
2014–17, B for 2018–20, C for 2021–23). It is the only out-of-sample record for 2014–23 (the pin's own 2014–17 is
in-sample). M70 added the half-rotation rule there (0.953 → 1.202). The 10% stop is a number from the paper (Han, Zhou
& Zhu 2016), not tuned on this data, so the same stitched test says whether its gain survives out of sample.

Books, each at offset 0 and in four decision-day tranches (offsets 0/5/10/15), stitched as in M70
(`notebooks/m85_stitched_stop.py`):

| Book | Pieces |
|---|---|
| book (M52) | m49_{a,b,c} |
| book + stop | the same with `stop_loss_frac: 0.1` (new configs `m85_{a,c}_s10*`; B is `m72_stop10_b2` / `m73_stop10_off*`) |
| half (M70) | 50/50 book and its rotation |
| half + stop (the M78 form) | both sleeves with the stop (new `m85_rot_{a,c}_s10*`; B is `m78_rot_s10*`) |

Information only, not a candidate. Known before: M70 and M78 results; nothing of the A/C pieces with a stop.

## Results (`uv run python notebooks/m85_stitched_stop.py`; runs in `reports/m85_runs.txt` plus the M49/M59/M70/M72/M73/M78 runs files)

Stitched 2014–23, each piece out of sample:

| Book | Offset 0: CAGR / max DD / Calmar | Four tranches: CAGR / max DD / Calmar |
|---|---|---|
| book (M52) | 24.84% / 26.07% / 0.953 | 25.47% / 26.65% / 0.956 |
| half (M70) | 28.37% / 23.60% / 1.202 | 29.16% / 25.16% / 1.159 |
| book + 10% stop | 22.84% / 16.41% / 1.392 | 22.77% / 17.82% / 1.278 |
| **half + 10% stop** | 25.94% / 17.46% / **1.485** | 26.09% / 16.91% / **1.543** |

Per piece, Calmar (half + stop, tranches vs book, tranches): 2014–17 1.583 vs 1.522; 2018–20 1.068 vs 0.783; 2021–23
2.637 vs 2.513. The half + stop book wins every piece; the stop alone loses 2014–17 at offset 0 (1.325 vs 1.557).

**Information:** out of sample, the 10% stop lifts Calmar in every form (+0.3 to +0.4), and the half + stop book (M78's
form) gives the best out-of-sample record found: 1.543, drawdown 16.9% vs 26.7%, for about 1 point less CAGR than the
plain book in tranches here (26.1% vs 25.5% — in fact 0.6 points *more*; the in-sample cost vs the pin is ~2.5
points). The pin's in-sample 2014–17 (29.1% CAGR, 2.070) is what M78 loses to; on the out-of-sample A setting the plain
book makes 20.1% there and the half + stop book 23.6%.
