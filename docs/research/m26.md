# M26: the pre-2010 jumps behind M25's refused runs

Pre-registration, written and committed before the dataset is built or any M26 run (2026-09-30, Claude). No `--final`.

## The problem

All nine M25 runs (2007-04-02..2009-12-31) were refused by the data gate: they held AKRUTI, COREEDUTEC or SATYAMCOMP
through an unexplained jump. M16 reviewed unexplained jumps from 2009 on; 2005–2008 never were. Scanning the same way
(jump dated 2006–2009, name passes price ≥ ₹50 and 50-session median turnover ≥ ₹5 crore on some session within a
year after) gives 23 jumps. Each was checked against the feed, the raw bhavcopy (NSE's 2006–07 PREVCLOSE is not
adjusted, so it cannot confirm a split) and the prices and volumes around the date:

- **10 are corporate actions** the data did not adjust. New `manual` override rows (symbols as traded then):
  ANSALINFRA 2006-05-10 and 2007-04-23 (0.5 each), KPIT 2007-01-04 (bonus 1:1 + FV 5→2, 0.2; the feed had only the
  bonus), COREPROTEC 2007-06-06 (FV 10→2), DABUR 2006-01-19 (bonus 1:1), HOTELEELA 2006-09-08 (FV 10→2),
  INDIABULLS 2007-01-02 (demerger; ex-date close / cum close, as TEXINFRA), IVRCLINFRA 2006-03-29 (FV 10→2),
  KALPATPOWR 2006-04-13 (0.5), NAGARCONST 2006-09-20 (0.5). Six of these are not in the feed at all; the factor is
  read from an ex-date open at 0.200–0.218 or 0.502–0.525 of the cum close, with no crash-like volume.
- **13 are real moves** (verified moves): AKRUTI 2009-03-26, COREPROTEC 2008-10-10 and 10-13, ORCHIDCHEM
  2008-03-17, SATYAMCOMP 2009-01-07 and 01-09, SUZLON and UNITECH 2008-10-24, HEXAWARE 2009-02-12, SKUMARSYNF
  2008-10-13, SPICETELE 2009-01-30, 02-02 and 02-12. Each has volume many times the session before and no feed event.

All rows are dated before 2009-12, and adjustment only rescales prices before an event, so no bar from 2010 on changes.

## The build and runs (question `momentum-m26-early`)

`nse_research@2026-09-30d` from `nse_research_linked.yaml`. Expected: 23 fewer unexplained jumps than 2026-09-30c
(1,070), give or take any raw sessions added since; all checks pass; `adj_*` unchanged for dates from 2010-01-01.

- `m26_check_gold20_invvol_b2`: the research reference on the new dataset. It must match its pin's metrics exactly
  (22.80% / 32.05% / 0.712); if not, the difference is traced before anything else.
- `m26_*` (nine configs): the M25 configs with only `dataset` changed. M25's hypotheses (H1 gold, H2 inverse-vol),
  reporting and "what follows" apply unchanged. If the gate still refuses a run, the names are listed and the run
  is not forced.

## Disclosure

The classification was made from prices, volumes and the feed, before any M25/M26 result existed (none could be
computed: the gate refused them). Six factors are inferred from prices alone; a wrong one would move only 2006–2007
prices of that name.
