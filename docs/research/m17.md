# M17: how sure is the inverse-vol edge? (a bootstrap check, no new strategy)

Pre-registration, written and committed before the analysis is run (2026-09-30, Claude working alone overnight at the
user's request). Development period 2010-01-04..2023-12-31 only; no `--final`; no new backtests.

## Why

Across M5–M16 about thirty momentum variants were tried on the same fourteen years. The recommended book (book 2 with
inverse-vol weights) wins every paired check so far, but by Calmar margins of 0.02–0.06 while the rebalance day alone
moves Calmar by 0.08. This measures how much of each margin could be luck of the path, so the user can weigh it before
paper or live money.

## Method (`notebooks/m17_bootstrap.py`)

Daily returns over 2010-01-04..2023-12-29 from the pinned M16 runs' `equity.parquet` (dataset `nse_research@2026-09-30c`):

| Label | Source |
|---|---|
| A | `momentum/m16_invvol_b2` (recommended) |
| B | `momentum/m16_b2` (equal weight, 40 names; the running `momentum_top40` book's rules) |
| C | `momentum/m16_b1` (equal weight, 30 names; the running `momentum_voladj` book's rules) |
| D | 12-1 momentum baseline, recomputed with `mb.evaluation.baselines.momentum_curve` on the same dataset |
| E | Nifty 500 TRI buy-and-hold (the baseline file), on the same sessions |

Paired stationary bootstrap (Politis–Romano): one set of resampled session indices is used for all five series, mean
block length 63 sessions (about a quarter, so drawdowns of a few months stay intact), 5,000 resamples, seed 20260930.
For each resample: CAGR, max drawdown, Calmar of each series. Reported: for A against each of B–E, the share of
resamples where A's Calmar is higher, and the 5th–95th percentile of the Calmar and CAGR differences. The actual
(unresampled) numbers must match the pinned runs' metrics (a check on the notebook).

## How it will be read

- Share ≥ 0.90: the edge is unlikely to be path luck alone.
- 0.70–0.90: the edge is suggestive; keep the choice for its other reasons (lower drawdown), not as proven.
- < 0.70: within noise.

Whatever the result, nothing is adopted or dropped by this check: it is evidence for the user's decision, and it cannot
correct for the ~30 variants tried (a bootstrap of one path does not know how many paths were searched). Block-bootstrap
shares on overlapping strategies are optimistic when the strategies are highly correlated, since their difference is
small but steady; the correlation of daily returns is reported beside each share.

## Disclosure

- All inputs are known results (M16 pins). The bootstrap outcome is not.
- Block length and resample count were chosen before running; no other settings will be tried and reported in their place.

Reading (by the pre-registered bands):

- **Against the index and the plain 12-1 baseline: unlikely to be path luck** (98.5%, 99.6%). The edge over the index
  is mostly return (+6 to +21 points a year); over 12-1 it is mostly smaller drawdowns.
- **Inverse-vol vs equal weight on the same 40 names: 97.2%**, but the daily returns are 0.995 correlated, which is the
  case the pre-registration flagged as optimistic. What is robust is the drawdown side (a small, steady cut); whether it
  also adds return is a coin flip weighted 79/21.
- **Book 2 inverse-vol vs book 1 (the 30-name running book): 83.4%, suggestive only.**
- The spread of any one strategy's Calmar across resamples (A: 0.30 to 1.32) is far wider than any gap between the
  variants. Expect live Calmar anywhere in that range, whichever variant runs.

None of this corrects for the ~30 variants tried. Nothing is adopted or dropped; the recommendation stands for the reasons
it had (it wins every paired check, with a lower drawdown).

Side note: the 12-1 baseline recorded on `2026-09-30c` is 0.473 (0.446 on `2026-09-30b`): the M16 corrections raised
the plain baseline more than the strategies. The M16 conclusion (pins and recommendation) does not depend on it; every
M16 run still beats both baselines on the whole period.
