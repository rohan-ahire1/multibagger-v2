# M37: is the month-end decision day better out of sample?

Pre-registration (2026-10-01, Claude), committed before these runs. Information only: nothing can be adopted, the pin
`momentum/m33_adv2cr_gold20_b2` already decides at the month-end.

## Why

M36's bootstrap found that the pin (deciding on the last session of the month) beats the same book spread over
offsets 0/5/10/15 in 96.9% of resamples of 2010–2023. If that is a real turn-of-month effect and not a feature of
this one sample, it should also show in the untouched 2007–09 window. If it does not, the pin's 2010–2023 edge over
its own other decision days (0.865 vs 0.820 / 0.718 / 0.812) should be treated as partly luck.

## Runs (question `momentum-m37-decision-day`)

`m35_early_adv2cr_gold20_b2` (offset 0; run 20261001-140436-3149b70f, Calmar 0.109, CAGR 7.08%) and
`m37_early_adv2cr_gold20_off{5,10,15}_b2` (same with `decision_offset_sessions` 5, 10, 15), on
2007-04-02..2009-12-31, `nse_research@2026-10-01b`.

Read-out, fixed now: the month-end effect is "confirmed" if offset 0 has the highest CAGR of the four; "not
confirmed" otherwise. CAGR, not Calmar, because the window's drawdown is the 2008 crash for all four. One window of
2.75 years is weak evidence either way; it changes only how the result is described, not any config.
