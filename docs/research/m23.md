# M23: does the gold sleeve help the other books too?

Pre-registration, written and committed before any run (2026-09-30, Claude working alone overnight). Development
period 2010-01-04..2023-12-31 only; no `--final`. No new code: the M19 option on other configs.

## Why

M19 tested the 20% gold sleeve on one book (`m16_invvol_b2`, 40 names, inverse-vol). A diversifier that works for a
real reason should help any momentum book, not only the one it was tuned on. The other three M16 references are the
natural test.

## Runs (question `momentum-m23-gold-books`)

| Config | Is | Against |
|---|---|---|
| `m23_gold20_b1` | `m16_b1` (30 names, equal weight) + `fixed_weights: {GOLDBEES: 0.20}` | `momentum/m16_b1` (0.604) |
| `m23_gold20_b2` | `m16_b2` (40 names, equal weight) + the same | `momentum/m16_b2` (0.634) |
| `m23_gold20_invvol_b1` | `m16_invvol_b1` (30 names, inverse-vol) + the same | `momentum/m16_invvol_b1` (0.623) |

Read as: the sleeve generalizes if it raises whole-period Calmar and lowers max DD on all three. Each is also judged by
the usual bar against its own pin, reported but not used to adopt anything (the research reference stays
`m19_gold20_invvol_b2`).

## Disclosure

All M19–M22 results are known, including that the sleeve costs return in fold 2 on book 2. Book 1 has a weaker fold 2
than book 2 (1.40 and 1.38 against 1.60 and 1.64), so it may pass there more easily.

## Results (2026-09-30): the sleeve generalizes

Question `momentum-m23-gold-books` (report `reports/momentum-m23-gold-books.md`, regenerated against each pin):

| Config | Run | CAGR | Max DD | Calmar | f1 / f2 / f3 | Its pin: Calmar, max DD, f1 / f2 / f3 | Bar |
|---|---|---|---|---|---|---|---|
| `m23_gold20_b1` | 20260929-204356-5209524c | 22.09% | 31.72% | 0.697 | 0.394 / 1.458 / 0.800 | 0.604, 40.62%, 0.283 / 1.399 / 0.680 | passes |
| `m23_gold20_b2` | 20260929-204406-9fedeb52 | 22.35% | 32.79% | 0.681 | 0.417 / 1.598 / 0.772 | 0.634, 39.28%, 0.299 / 1.597 / 0.702 | passes (f2 by 0.001) |
| `m23_gold20_invvol_b1` | 20260929-204415-fa33eaa7 | 22.14% | 31.27% | 0.708 | 0.438 / 1.482 / 0.832 | 0.623, 39.62%, 0.321 / 1.381 / 0.720 | passes |

On all three books the 20% sleeve raises whole-period Calmar (+0.05 to +0.09) and cuts max DD by 6.5–8.9 points, at a
cost of 2.4–2.6 points of CAGR. It passes the full bar against each book's own pin. On book 1 it even raises fold 2,
where book 2's sleeve only ties. Together with M19 (book 2, inverse-vol: +0.045, −6.3 points), that is four of four
books, so the effect is not specific to the config it was first tried on.

The research reference stays `m19_gold20_invvol_b2` (0.712); `m23_gold20_invvol_b1` (0.708) is its 30-name twin.
Both need the user's decision before paper use (an ETF in a stocks-only book, and paper code support).
