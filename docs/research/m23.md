# M23: does the gold sleeve help the other books too?

Pre-registration, written and committed before any run (2026-09-30, Claude working alone overnight). Development
period 2010-01-04..2023-12-31 only; no `--final`. No new code: the M19 option on other configs.

## Why

M19 tested the 20% gold sleeve on one book (`m16_invvol_b2`, 40 names, inverse-vol). A diversifier that works for a
real reason should help any momentum book, not only the one it was tuned on. The other three M16 references are the
natural test.

## Runs (question `momentum-m23-gold-books`)

| Config | Is | Against |
|---|---|---|
| `m23_gold20_b1` | `m16_b1` (30 names, equal weight) + `fixed_weights: {GOLDBEES: 0.20}` | `momentum/m16_b1` (0.604) |
| `m23_gold20_b2` | `m16_b2` (40 names, equal weight) + the same | `momentum/m16_b2` (0.634) |
| `m23_gold20_invvol_b1` | `m16_invvol_b1` (30 names, inverse-vol) + the same | `momentum/m16_invvol_b1` (0.623) |

Read as: the sleeve generalizes if it raises whole-period Calmar and lowers max DD on all three. Each is also judged by
the usual bar against its own pin, reported but not used to adopt anything (the research reference stays
`m19_gold20_invvol_b2`).

## Disclosure

All M19–M22 results are known, including that the sleeve costs return in fold 2 on book 2. Book 1 has a weaker fold 2
than book 2 (1.40 and 1.38 against 1.60 and 1.64), so it may pass there more easily.
