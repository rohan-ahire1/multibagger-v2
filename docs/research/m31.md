# M31: missing demergers, and manual fixes that never applied

Pre-registration (2026-10-01, Claude), written and committed before the new dataset is built. Development period
2010-01-04..2023-12-31 only; no `--final`.

## Why

The M30 run `m30_htp_raw_gold20_b2` was refused by the data gate: it held FEL through 2016-05-11, an 87% overnight
fall that is the demerger of Future Retail (the feed has no factor). A review of the unexplained jumps in names
trading at least ₹2 crore a day since 2009 found:

1. **Three manual overrides that never applied** (`ca_matches.parquet` status `unmatched`): ADANIENT 2015-06-03
   (M16), INDIABULLS 2007-01-02 (M26) and TEXINFRA 2010-11-01 (M16). Each factor was set from the ex-date close
   because the open was the cum price less the band, set before price discovery. The matcher compares a factor only
   with open / previous close, so it rejected all three and the dataset kept the unadjusted fall.
2. **18 events the feed misses**, each checked against a news or exchange source: demergers FEL, FELDVR,
   ZEEMEDIA 2010, TRIVENI 2011, TCI 2016, THOMASCOOK 2019 (Quess shares), SINTEX 2017, SANOFI 2024, RAYMOND 2024 and
   2025, ROSSELLIND 2024, HERCULES 2024, KESORAMIND 2025, SIEMENS 2025, QUESS 2025, ABFRL 2025; BHAGERIA's 2016
   split; IDEA's 2019 rights issue (factor = theoretical ex-rights price).

The other large jumps in that list are real crashes or rallies (SUZLON 2013, UNITECH 2015, RCOM, YESBANK 2020, JET
AIRWAYS 2019, ...) or small-cap split-plus-bonus events. They are left alone: the gate only matters for a name a
run holds, and a real move needs a verified-move row only then.

## Changes

- `adjust.match_share_events`: when the open does not fit a **manual** override, the close / previous close is
  tried as well (same window, same tolerance). Feed events still match on the open only, so no feed match changes.
- 18 rows appended to `corporate_actions_overrides.csv` (factor = ex-date open / cum close, or the close where the
  open was before price discovery, as the M16/M18/M26 rows do).
- New dataset `nse_research@2026-10-01` from `nse_research_linked.yaml`. Expected: all checks pass, unexplained jumps
  1,037 → about 1,016 (21 fewer), every manual override `matched` or `applied_small`.
