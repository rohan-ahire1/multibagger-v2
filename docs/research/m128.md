# M128: rank on return over downside deviation (pre-registered 2026-10-23, before any M128 backtest)

Tenth cycle of the autonomous loop.

## Idea and sources

M106 ranks on the 273/14-session return divided by the standard deviation of daily log returns (the "vol-adjusted"
momentum that Raju 2024, SSRN 4977717, finds best in India). The standard deviation punishes a stock's large up days
as much as its large down days, so a winner that got there in a few big up-gaps ranks below a smoother one with the
same return even when it never fell much. Reward-risk ranking with a downside-only risk measure is the obvious
alternative: Rachev, Jašić, Stoyanov & Fabozzi (2007, *Journal of Banking & Finance*, "Momentum strategies based on
reward-risk stock selection criteria") find reward-risk criteria give better risk-adjusted momentum than the plain
return, with thinner left tails; Leon, Navarro & Nieto (2016) compare 32 past-performance metrics for stock selection
and find partial-moment (Sortino-type) measures beat the Sharpe ratio; an AEA 2019 working paper reports partial-moment
momentum variants beating plain momentum. None is an Indian test. Never tried here (grep of docs/research: no downside
or semi-deviation score).

Checked and dropped this cycle (journal): scaled turnover (traded value / market cap, BacktestIndia 2026 blog: low
turnover momentum names beat high) needs shares outstanding, which NSE's PR archives give only for index members
(`ffix*.csv`), not M106's small caps; the delivery filter (M40) already covers speculative churn.

## Rule

Score = 273/14-session return / downside deviation, where downside deviation = sqrt(mean over the same 259 rows of
min(r, 0)^2), r the daily log return (target 0, Sortino). Everything else is M106: inverse-vol weights (84-session
stdev, unchanged), top 25, delivery and gap filters, 25% GOLDBEES, JUNIORBEES 200-day switch. Code: `RankingM128`
(`score_risk: stdev | downside`), `ParamsM128`, `ranked` in `targets.py`; `tests/test_m128_downside_score.py`.
